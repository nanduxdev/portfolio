# My Journey

I am a self-taught full-stack developer from Pimpri, Maharashtra. My journey began with curiosity about programming and has grown through consistent practice, online learning, real projects, and internships.

## 2026

### January – July: Software Trainee at HiddenBrains Infotech

- Worked as a **Software Trainee** at HiddenBrains Infotech.
- Gained practical experience in a professional software-development environment.
- Continued improving my full-stack development skills through hands-on work and real-world development practices.

### August – Present: Building PostForge AI

- Began building **PostForge AI**, a full-stack SaaS project.
- Focused on modern TypeScript-first development with Next.js, NestJS, PostgreSQL, Drizzle ORM, and a Turborepo monorepo setup.
- Worked on backend architecture, database design, authentication, API development, and AI-assisted product features.
- Continued learning how to build more scalable, production-minded applications.
## 2025

- Joined **Harkirat bhaiya’s Cohort 3** after a friend introduced me to his content.
- Learned and practiced the **MERN stack**: MongoDB, Express.js, React, and Node.js.
- Built full-stack projects and developed a stronger understanding of frontend-backend integration.
- Completed an internship at **Codtech IT Solutions** as a React.js Intern.
- Began moving beyond the MERN stack toward modern tools such as Next.js and TypeScript.

## 2024

- Learned the foundations of web development through **Apna College** tutorials by **Shraddha di's**.
- Studied **HTML**, **CSS**, and **JavaScript**.
- Built my early web interfaces and learned how browser-based applications are structured.
- Started turning programming practice into small real-world projects.

## 2023

- Began my programming journey with the **C language**.
- Learned basic programming concepts and started practicing foundational Data Structures and Algorithms.
- Followed the **Physics Wallah** YouTube coding challenge and learned from **Raghav Sir’s** tutorials.
- Developed the habit of learning consistently through YouTube, documentation, and hands-on coding.

## What I’m Building Now

Today, I am focused on becoming a stronger full-stack engineer by building production-minded applications with:

- TypeScript
- Next.js
- NestJS
- PostgreSQL and Drizzle ORM
- Better Auth and secure authentication flows
- Turborepo monorepos
- Docker-based local development
- AI-assisted developer tools and LLM integrations

My goal is to keep learning in public, contribute to open source, build useful SaaS products, and grow through real engineering work.
